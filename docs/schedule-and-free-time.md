# 予定一覧と空き時間 — 実装仕様書

作成 2026-08-31。**先に納品する引き継ぎ書**。

## 何を作るか

1. **IRIS を開いたら、しばらくの予定一覧が出る**（web UI）
2. **空き時間をコピペできる**（人に「いつ空いてる？」と聞かれたときに貼るため）

## 決まっていること（利用者、2026-08-31）

| | |
|---|---|
| 空きとみなす枠 | **9:00〜24:00** |
| 最短の塊 | **60分**。それ未満は空きとして出さない |
| 終日の予定 | **その日を潰す。ただし但し書きを添える**（何が潰しているか分かるように） |

### 祝日だけは例外にする — 要確認

終日の予定9件のうち**4件が「日本の祝日」**（敬老の日・国民の休日・秋分の日・スポーツの日）。
これを潰すと**休日が一日中埋まっている**ことになり、実態と逆になる。

**「日本の祝日」カレンダーの終日だけは潰さない**を既定とする。祝日は予定ではなく印だから。
違うなら直す — この一行は利用者の言葉ではなく、こちらの判断。

## 出典を必ず添える — これが要件の中心

**空き時間は他人に渡すもの**で、間違いの行き先が自分ではない。

2026-08-27、Google カレンダーの更新トークンが失効して**丸一日、授業が全部消えていた**。
あの状態で空き時間を出せば、**授業中の時間を「空いています」として送ることになる。**

```
9/1(月) 13:00-15:00, 18:00-20:00
9/2(火) 9:00-24:00  ※ 琉大祭（終日）

（google・icloud から作成 / 2026-09-01 14:30 時点）
```

**源が欠けているときは空き時間を出さない。**警告つきで出しても、
**コピペした先には警告が付いていかない。** `/api/calendar` の `contributions` で
設定済みの源が全部そろっているかを見て、欠けていれば理由を出して空き時間は出さない。

## 予定一覧

- 期間は既定 7日。web UI のパネルに出す。
- 日ごとに区切り、時刻・題名・カレンダー名。終日は `終日` と出す。
- **題名は整理番号を落とす**（帯と同じ規則: `病理学Ⅱ25-26` → `病理学Ⅱ`）。
  menubar 側の `subject()` と同じ扱いを web 側にも置く。**規則は一箇所に持つこと。**

## 空き時間

- 予定の隙間を 9:00〜24:00 の中で拾い、60分未満は捨てる。
- 終日があればその日は空き無し、ただし理由を注記。
- **コピー用のテキストは、画面の見た目ではなく専用に組む。**
  貼る先はメッセージアプリなので、記号や色は落として素の文字にする。

## 順番

**予定一覧が先、空き時間が後。**一覧が見えれば「この予定は空きを潰すのか」を
実物で判断できる。先に規則を決めると想像で決めることになる。

## 足場

- サーバ: `GET /api/calendar?days=N` が既にある。**新しい endpoint は要らない**
  （空き時間の計算はサーバ側に置く方が、web と帯の両方から使えて良い）。
- web: `src/components/Telemetry.tsx` の `Panel` を使う。`src/api.ts` に取得口を足す。
- 空き時間の計算は純関数にして `scripts/test-*.ts` で検算する。
  **境界（開始ちょうど・終了ちょうど・日をまたぐ予定）は必ずテストに入れる。**
