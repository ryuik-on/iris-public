# 講義日程 PDF から試験を取り出す — 実装仕様書

作成 2026-08-27。**先に納品する引き継ぎ書**。途中で止まっても、これを読めば続けられる。

## なぜ作るか

いま IRIS の試験カウントダウンは **カレンダーに誰かが入れたかどうか** に完全に依存している。

2026-08-27 02:33 に Google カレンダーの更新トークンが失効し、**明日の試験がその瞬間から見えなくなった**。
カレンダーは人が入力するので抜けるし、片方の源が落ちれば黙って消える。

大学が出している `令和8（2026）年度医学科講義日程_2026.6.19版.pdf` は一次資料で、
13ページ・「試験」159件が入っている。**入力漏れがない**。ここから取るのが本筋。

## 元データの形

- 月ごとのカレンダー格子。**列＝日、行＝時限**（列見出しに日付の数字、行に1〜7限）。
- テキストは座標付きの単語としてバラバラに出る。`page.get_text('words')` で
  `(x0, y0, x1, y1, word, block, line, word_no)`。
- **罫線が引かれている**。`page.get_drawings()` から縦線68本・横線67本が取れ、
  列は約60px間隔で規則的。**セル境界はこの罫線から決める**。単語の x 間隔から
  推測してはならない（後述の失敗を参照）。
- 「◯月」という月見出しは**単語として取れない**。月の決定方法は要調査
  （ページ内の日付の連続性、またはページ順から導く）。

## やること

### 1. 格子の復元

罫線から列境界と行境界を作り、各単語を (列, 行) に割り当てる。
セル内の**日付の数字**（1〜31 の単独トークン）が、その列の日付。

### 2. 日付の決定 — **解決済み（2026-08-27）**

格子の実際の形はこうだった。

- **1日 = 8列**。左端の1列に日付、続く7列が1〜7限。
- 日付は**週ブロックの見出し行**にあり、その**すぐ下の行に曜日**（月火水木金）が並ぶ。
- 週ブロックは縦に積まれ、ページに複数ある。

したがって、ある予定の日付は:
1. その語の y から行を求め、**上に遡って「単独数字が3つ以上 かつ 直下の行に曜日が3つ以上」の行**を探す。それが週ブロックの見出し。
2. 見出し行の日付を x 昇順に並べ、**対象の x 以下で最も右のもの**を選ぶ。その**順番（index）が同じ位置の曜日**と対になる。

曜日は日付の左端ではなく**8列ブロックの中央**にあるので、
「x 以下で最も近い曜日」を取ると1日ぶんずれる。**index で対応させること。**

月は (日, 曜日) の組と**年度（2026年4月〜2027年3月）**から一意に決まる。
別途の月見出しは PDF に単語として存在しないので、この方法を使う。

**検算は通っている**（下記の3件すべて、日付と曜日が一致）。

### 3. 試験だけ抜く

既存の `server/services/exam.ts` と同じ規則を再利用する。二重定義しない。
- 拾う: `試験|考査|模試|CBT|OSCE`
- 除く: `再試|追試|（再）`

### 4. 検算（これが本体）

**当てずっぽうで通ったことにしない唯一の方法**。既知の正解と突き合わせる。

| 予定 | 正しい日付 | 出典 |
|---|---|---|
| 病理学Ⅱ25-26 | 2026-08-26 | 8/26 の帯（Google 生存時）「今日は 08:30 から」 |
| 病理学Ⅰ21-22 | 2026-08-27 | 同「明日は 08:30 から」 |
| 微生物・免疫学試験（後半） | 2026-08-28 | 8/26 の `/api/exam/next`（あと2日） |

### 5. IRIS に源として足す

**カレンダーより弱い扱いにする。** PDF は「6.19版」で、後から変更が入る。
- 同じ試験がカレンダーにあれば**カレンダーを優先**
- カレンダーに無いときだけ PDF が答える
- 答えたときは**出典が PDF であることを結果に同行させる**（版の日付つき）

## 失敗として記録しておくこと

設計中、単語の x 間隔から列を推測しようとして**外した**。

```
病理学Ⅱ23-24 → 病理学Ⅱ25-26  で x が +272
病理学Ⅱ25-26 → 微生物試験      で x が +899（2日ぶんのはず）
```

間隔が一定でないので、**x の差から日数は出せない**。罫線を使う理由がこれ。
そして最初の探索は「対象のすぐ上の数字」を日付と見て **21** を得たが、正解は **28** だった。
**1週間ずれた日付を「あと1日」と出す道具は、無いより悪い。**

## 実装の結果（2026-08-27）

`scripts/extract-schedule.py` — PDF を一度だけ読んで JSON にする。IRIS は JSON だけを読む。
PDF を読める道具がこの機械には PyMuPDF しかなく、日程表は版で管理される資料で
毎回パースするものではないため。

```
python3 scripts/extract-schedule.py .iris/schedule/講義日程_2026.6.19.pdf \
        .iris/schedule/exams-2026.6.19.json 2026 M2
```

### 学年でページを絞る

日程表は学年ごとにページが分かれている（p2-3=M1, **p4-5=M2**, p6-7=M3, p8-9=M4,
p10-11=M5, p12-13=M6）。絞らないと他学年の CBT 本試験や総合試験まで拾う。
**自分が受けない試験のカウントダウンを出すのは害にしかならない。**

判定は `M2講義|M2本試験|M2および|M2学士|M2（` をページ全文から探す。
`\bM2\b` は効かない — 「M2講義」の 2 と 講 の間に語境界が無い（どちらも語構成文字）。
そして見出しはテキスト順の先頭には来ない（時限の数字が先に並ぶ）ので、全文を見る。

### セル単位で読む

語単位で拾うと題名が割れ、「16定期試験」「期試験」「（試験」のような断片になる。
罫線で作ったセルの中の語をまとめて一つの題名にする。

### 月は単調性で決める

(日, 曜日) だけでは月が絞れないことが多い。ページ内では週ブロックが上から下へ
時系列に並ぶので、**日付が単調に増える**ことを制約に使う。
最初にひとつに絞れたものを起点に前後へ広げる。**起点が無いページは何も決めない** —
適当な月から始めればページまるごと一斉にずれる。

## 訂正（2026-09-04）

**上に書いてある「いまの結果」は間違っていた。**7件中5件の日付がずれ、
本物の試験が4件抜けていた。以下がその記録。

### 何が壊れていたか

日付行を「**下に曜日の行があるもの**」と定義していた。ところが曜日は
**月ブロックの先頭の週にしか書かれていない**。そのため、ほとんどの週で
正しい日付行が条件を満たさず捨てられ、**曜日行を持つ別の週まで遡って、
そこの日番号を使っていた。**

`分子細胞生物学中間試験(1)` は 5/11 の週にあるのに、4/20 の週の日番号を
拾って「4月20日」になっていた。最大3週ずれる。

**検算の2件（神経科学本試験 8/24・微生物免疫学試験 8/28）は、たまたま
月ブロックの先頭の週にあった。**そこだけは正しい行を見ていたので通り、
**通った検算が、壊れた仕組みを正しく見せていた。**「検算の2件とも通って
いる」と書いてあるのは、そういう意味では嘘ではなく、**足りなかった**。

さらに、セルの中で語が折り返されて「試 験」と空白が入っている行が
`試験` の正規表現に当たらず、**病理学の試験4件が丸ごと出ていなかった。**
同じ理由で「（再 試）」が再試として弾かれず、再試が本試験の顔で並んでいた。

### いま何をしているか

**月は読む。推測しない。**左端の細い列に月見出しがある（数字の下に「月」）。
日番号が前より小さくなったところで次の月に進む。(日, 曜日) から月を絞る
やり方はやめた — 候補が複数残り、埋めた瞬間にずれる。

日番号は**列で絞る**。時限の中にも数字があり（「病理学Ⅱ43-44」の 43）、
拾うとその行の月が一つ進む。日番号の x はページ内で一定なので、頻度の
多い5本を日付の列とする。

列は**その行に実在する縦線だけ**で作る。ページ中の縦線を全部使うと、
別の行の仕切りが結合セルを横切って題名を割る。これで「（該当者）」
「(6F602)」「臨床2F」が戻った。**再実施の回が本試験と同じ顔で並ぶ**のが
止まった。

判定の前に空白を落とす。折り返しで入った空白が、再試を本試験にしていた。
