# 課題台帳の `自動判定` — 消したシート数式の原本

2026-09-02 に、課題台帳タブの **O2** から消した ARRAYFORMULA。判定は IRIS
（`server/core/fdp_verdict.ts`）に移した。**シート上にはもう存在しないので、
ここが唯一の原本。**

消す前の状態: 10行すべて埋まっていて、完了4・順調4・更新停止2。IRIS の再現は
10行とも一致していた。実データに出ていなかった `遅延` は、T007 の期限を一時的に
2026/01/15 へ動かして突き合わせ済み（シートは「期限超過」、IRIS は「遅延」）。

```
=ARRAYFORMULA(IF(A2:A="","",IF(G2:G="完了","完了",IF(F2:F<TODAY(),"期限超過",IF((F2:F>=TODAY())*(F2:F<=TODAY()+3),"期限間近",IF((E2:E<=TODAY())*(TODAY()-K2:K>=7),"更新停止",IF(IFERROR((E2:E<=TODAY())*(F2:F>TODAY())*(H2:H<1)*(((TODAY()-E2:E)/(F2:F-E2:E)-H2:H)>0.25),FALSE),"進捗停滞","順調")))))))
```

列の対応（課題台帳タブ）:

| 列 | 見出し | 式での役割 |
|---|---|---|
| A | ID | 空なら判定しない（行が無いのと同じ） |
| E | 開始予定日 | 「もう始まっているはず」の境目 |
| F | 期限 | 期限超過・期限間近・進捗停滞の分母 |
| G | 状態 | `完了` なら他を一切見ない |
| H | 進捗率 | 0〜1。進捗停滞の判定に使う |
| K | 最終更新日 | 更新停止の起点 |

## 判定の順序（ここが仕様の本体）

上から順に、最初に当たったものを返す。**順序そのものが仕様**で、たとえば期限を
過ぎていて同時に7日動いていない課題は `期限超過` であって `更新停止` ではない。

1. **完了** — `状態` が「完了」。他の条件を一切見ない。
2. **期限超過** — 期限が今日より前。IRIS 側の語彙では **遅延**。
3. **期限間近** — 期限が今日から3日以内（今日を含む）。
4. **更新停止** — 開始予定日を過ぎていて、`最終更新日` から7日以上。
5. **進捗停滞** — 開始済み・期限内・未完了で、**経過した時間の割合が進捗率を
   0.25 より大きく上回っている**。`IFERROR(…, FALSE)` が付いているのは、
   `F=E`（開始と期限が同日）でゼロ除算になる行を「停滞ではない」に倒すため。
6. **順調** — どれにも当たらなかった。

## 語彙の食い違い

シートは `期限超過`、IRIS は `遅延`。同じ判定の別名で、`fdp_verdict.ts` の
`SHEET_SYNONYM` が対応表を持っている。**片方に寄せて書き換えないこと** —
この文書と突き合わせる時に、名前が違うことを知っている必要がある。

## この式を読んで直したこと（2026-09-02）

数式を消した直後にここへ書き写して、初めて再現との食い違いが三つ見つかった。
**突き合わせは「全行一致」と言い続けていた** — 照合が IRIS の語彙を数え上げて
いたので、シートにしか出せない言葉は比べる対象にすら入っていなかった。

- **期限間近が判定として存在しなかった。**`dueSoonDays` は設定タブから読み
  込まれるだけで、一度も使われていなかった。
- **進捗停滞が存在しなかった。**該当する行が実データに無かったので、
  一度も表に出なかった。
- **更新停止・進捗停滞の除外条件が違った。**数式は状態を見ず
  `開始予定日 <= 今日` だけで掛けている。こちらは「開始が先で、かつ状態が
  未着手なら順調」としていたので、**開始日が先なのに進行中になっている行**
  だけ答えが割れていた（シートは順調、こちらは更新停止）。数式に合わせた。
  拾わせたければ、それは再現ではなく新しい決定になる。

意図的に再現していないもの:

- **空セルを 0 として扱う挙動。**Sheets では空欄が 0 になるので、
  `最終更新日` が空の行は `TODAY()-0 >= 7` が真になり、数式では 更新停止 に
  倒れる。これは仕様ではなく式の副作用なので、こちらは「日付が読めないなら
  判定しない」にしてある。

## 戻したくなったら

O2 に上の式をそのまま貼る。O3 以下には何も書かない（ARRAYFORMULA が下まで埋める）。
