# 暗い画面の色

IRIS の面はすべて暗い。地の色は `#0C0E12` で、これは利用者が選んだもの
（右レールの背景）。この文書は、**その上に何色をいくつ置いていいか**を決める。

調べた記事はどれも同じ四つを言っていた。以下はその要約と、この機械での適用。

---

## 1. 純黒を使わない。純白も使わない

`#000000` の地に `#FFFFFF` の文字は、対比が最大になるぶん**目が疲れる**。
暗い面では、地をわずかに持ち上げ、文字をわずかに落とす。

この機械では **地 `#0C0E12` / 文字 `#E6ECF2`**。どちらも端に寄っていない。

## 2. 彩度を落とす。**明色版より 20 ポイントほど**

**暗い地の上で彩度の高い色は光学的に振動する。**目の焦点が定まらず、長く見て
いられない。明るい画面で正しかった色を、そのまま暗い画面に持ってくると必ず
これが起きる。

2026-09-01 に実際に起きた例：注意の色が `#FBBF24`（彩度 96% の黄）だった。
利用者の指摘は「色の使い方がだめだ、黄色やめて」。橙へ寄せ、彩度を 68% に
落として `#D98B4A` にした。**対比は 11.6:1 → 7.1:1 に下がったが、それでいい**
— 基準は 4.5:1 で、11.6 は「読める」ではなく「明るすぎる」だった。

## 3. 高さは影ではなく明るさで表す

明るい画面では、浮いている面に影を落とす。**暗い画面では影が見えない。**
代わりに、浮いている面ほど地を明るくする（Material の tonal elevation）。

この機械では二段だけ：**地 `#0C0E12` / 持ち上げた面 `#14181F`**。

## 4. 色数を絞る。大きい面は地の色で塗る

色は注意を配るための道具で、**多いほど一つあたりの意味が薄くなる。**
大きな面を強調色で塗らない — 暗い画面では、地のままにして、色は
**状態を言う小さい印**に取っておく。

## この機械で使う色（これで全部）

| 役割 | 値 | 対比 | どこで |
|---|---|---|---|
| 地 | `#0C0E12` | — | レール、盤、web |
| 持ち上げた面 | `#14181F` | — | 盤の中のパネル |
| 文字 | `#E6ECF2` | 16.2:1 | 本文 |
| 添え字 | `#8995A3` | 6.3:1 | 見出し、単位、補足 |
| 目盛りの軌道 | `#2A2F38` | — | 輪の下地 |
| IRIS の印 | `#5B9CF5` | — | 核だけ。**アクセントではなく、この道具の顔** |
| アクセント | `#5B9CF5` | 7.4:1 | リンク、選択中、主要操作、区切り |
| **良い / 手つかず** | `#6FAF91` | 7.6:1 | 使用量の輪（〜60%）、順調 |
| **注意** | `#C7915E` | 7.0:1 | 使用量の輪（60〜85%）、未更新、判断待ち、承認待ち |
| **危険** | `#C96D69` | 5.4:1 | 使用量の輪（85%〜）、期限超過 |

**十色。これ以上増やさない。**

### 画面に占める割合の目安

```
地と面・文字   85%
青（構造）     10%
橙（注意）      5%
```

**青が世界観、橙が視線の行き先。**青は構造 — リンク、選択中、区切り、進捗。
橙は**いま見るべきもの**だけ。二つを同じ強さで使うと、どちらも効かなくなる。

**橙をアクセントにしてはいけない**（2026-09-01 に一度やった）。そうすると橙が
「構造」と「注意」の二つの意味を持ち、**同じ色が二つの意味を持つと、
どちらでもなくなる。**そして画面には既に青がいる — レールの核で、これは
この道具の顔なので動かせない。

**状態色が画面の主役になったら、それは付けすぎ。**2026-09-01 の盤は、手が
要るのが2件なのに10行が色を持っていた。

### 規則

- **状態の三色（緑・橙・赤）は意味に予約されている。装飾に使わない。**
  緑は「まだある / 順調」、橙は「見に行くべき」、赤は「もう無い / 過ぎた」。
- **同じ意味には、どの面でも同じ色。**レールの輪と盤の点は同じ橙。
  片方だけ違うと、同じ状態が二つの色を持つ。
- **色はグループの中で区別しなければならない。グループそのものを言い直しては
  いけない。**判定は「色を外して何が失われるか」。判断待ちの3行を全部橙に
  しても、そのかたまりは位置と見出しでもう区別されている — **外しても何も
  失われないなら装飾。**課題の `未更新` は、同じ見出し・同じ大きさの中で
  T006 と T005 を分けているので、外すと一行ずつ読んで探すことになる
  — **失われるものがあるなら情報。**

  85/10/5 の割合は、この規則の代理指標でしかない。**割合より、この判定の方が
  正確。**
- **見出しの語まで塗らない。数だけ。**「7日超 2」を丸ごと橙にすると、
  「橙はいま見るべきものだけ」という約束が一行ごとに薄まる。
- **行を丸ごと塗らない。注意すべき語だけ。**「29日 未更新 ・ 期限まで76日」を
  全部橙にすると、警告なのは二文字なのに一行が警告に見える。数字は本文の色、
  期限は添え字の色、`未更新` だけが注意の色。
- **塗った丸を状態の印に使わない。**丸は「オンライン」「稼働中」の語彙で、
  稼働していないものに使うと意味がずれる。`○ △ ! —` のような記号なら、
  形そのものが違いを運ぶ。
- **色だけで意味を運ばない。**必ず文字か形を添える。色覚の問題で読めない人が
  いるのと、色は隣の色との関係でしか読めないため。
  （測定では、色付きの状態表示は文字のみより走査が約35%速い。**併用が最良で、
  色単独は最悪。**）
- **地は不透明にする。**半透明にすると、後ろにあるもので色が動く。同じ機械の
  二つの面が別の色に見えるのは、同じ数字が二箇所にあるのと同じ種類の間違い。
- **役割の欄にある用途以外に使わない。**とくに **罫や軌道のための色を文字に
  使わない。**`#2A2F38` は輪の下地で、文字にすると地に沈んで読めない。
  2026-09-01、web 側で 26% alpha の境界線用の色を「保留」の文字に使っていた。
  **「無彩色にした」と「見えない色にしていた」は、画面の上では見分けが付かない**
  — むしろ薄いのが正解に見えるので、報告されなければ気づけない。
